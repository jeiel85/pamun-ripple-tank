# 파문 투영기 — 최종 구현 명세

> 이 문서는 구현 에이전트가 단일 HTML 파일을 완성하는 데 필요한 내용을 모두 담는다. 목표 분량은 P0+P1 약 2,250줄, P2를 넣으면 약 2,400줄이다. 구현은 P0 → P1 → P2 순서로 하고, 범위가 넘치면 P2부터 잘라 낸다.
> 수치 가운데 "(튜닝)" 표시가 붙은 것은 초기값이다. 9장 수용 기준을 맞추는 데 필요하면 조정해도 된다. 표시가 없는 수치는 그대로 따른다.

---

## 0. 제작 제약 요약

- 결과물은 단일 HTML이다. 들어가는 것은 `<title>`, Google Fonts `<link>` 1개, `<style>`, 마크업, `<script>`뿐이다. `<!doctype>`·`<html>`·`<head>`·`<body>` 태그는 쓰지 않는다.
- 외부에서 불러오는 것은 Google Fonts 스타일시트 한 건뿐이다. 라이브러리 없이 raw WebGL2 + Canvas2D + WebAudio로 만든다. 이미지·오디오 에셋은 모두 절차적으로 생성한다.
- 다음은 쓰지 않는다: alert/confirm/prompt, 파일 다운로드, 마이크, 카메라, 서비스워커. 사용자에게 보여 줄 메시지는 페이지 안 토스트와 aria-live로 낸다.
- 기본은 무음이다. 오디오는 `#sound-toggle` 클릭 핸들러 안에서만 시작한다.
- 폰 폭 360~430 px에서 가로 스크롤이 없어야 한다. 터치 대상은 최소 44 px이다.
- localStorage는 편의 기능에만 쓰고, 읽기·쓰기를 모두 try/catch로 감싼다. 저장이 실패해도 페이지는 정상 동작한다.

## 1. 이름·한 줄 설명·`<title>`

| 항목 | 값 |
|---|---|
| 이름 | 파문 투영기 |
| `<title>` | `파문 투영기` |
| 한 줄 설명 | 불 끈 물리실험실의 물결통에 파라핀으로 벽을 그리고 울림돌을 놓으면, 물결이 닿는 거리가 박자가 되고 놓인 높이가 음정이 되는 파동 악기. |

**핵심 약속 3가지 (모든 결정의 기준)**
1. 로드 직후 첫 프레임부터 텅스텐빛 캐스틱 그물이 수조를 채운다. 무음이어도 울림돌이 램프빛으로 번쩍이고 발음 스트립에 리듬이 찍혀, '악기'라는 것이 보인다.
2. 톡 하면 다음 프레임에 물결이 생기고, 그 물결이 울림돌에 닿는 순간 음이 난다. 거리가 곧 시간이다.
3. 같은 배치는 어느 기기, 어느 창 크기에서도 같은 음악이 된다. 이를 위해 수조 크기를 고정하고, 시계를 하나로 두고, 전파 속도를 실측한다.

### 1.1 범위 계층

| 등급 | 내용 |
|---|---|
| **P0** (반드시) | 고정 수조와 뷰 변환(세로 화면 90° 회전 포함) · 파동 솔버와 안정성 장치 전부 · c_eff 실측 보정 · 단일 시계 · 탭 물방울 · 끌기 항적과 마하 표시 · 점적기·진동자 소스(프리셋 배치분 동작) · 유휴 비 · 파라핀 도구 · 울림돌 도구(놓기·옮기기·치우기·레인 스냅·직선 지연 표시) · 울림돌 판독 · 투영 셰이더 + LUT · Canvas2D 폴백 · 컨텍스트 소실 처리 · 오버레이(정적 캐시) · **발음 스트립** · 소리 토글·음량·타격음·물방울 소리·잔향·마스터 체인·안전 상한 · 명판·힌트·토스트·aria-live · 계기판(수심·템포·소파 장치·음계=평조·움직임 줄이기·멈춤·잠재우기) · 첫 장면 프리셋과 선행 계산 · 키보드(도구 1/2/6, 조준경, Space/M/B/C) · 감쇠 모드 · 탭 숨김 처리 · 리사이즈 · 적응 품질 · 에너지 E와 진동자 자동 게인 |

| **P2** | 스트로보(안전 장치 포함)와 틱 · 손짓 루프 녹음(R) · 배음렬 음계 |

심사2의 계층안과 두 군데가 다르다.
- 마하 표시를 P0로 올렸다. 포인터 속도 계산만 있으면 되는 한 줄짜리이고, 5분 발견의 입구이기 때문이다.
- 메아리 라벨을 P1로 올렸다. 공유 순간인 '메아리 1.00박'의 판정 근거이기 때문이다.

### 1.3 이식(graft) 결정

- **채택 1: 발음 스트립 (P0)** — 4.6에서 설명.
- **채택 2: 직선 대 실측 캘리퍼 (P1)** — 3.10에서 설명.
- **채택 3: '내 수조' 자동 저장 (P1)** — 8장에서 설명.
- 기각한 것과 그 이유는 별도 필드에 적었다. 요지는 네 가지다.
  - 탭 즉시성을 해치는 제스처 문법은 받지 않는다.
  - 정체성과 무관한 이스터에그는 받지 않는다.
  - UI 표면을 늘리는 스코프·오브젝트 버튼은 받지 않는다.
  - must_fix와 겹치는 항목은 본문에 반영했으므로 graft로 따로 세지 않는다.

## 2. 경험 흐름

### 첫 정지 프레임 (0초, 입력 없음)

- 짙은 청록 암실 바탕에 64×36 cm 수조가 화면을 꽉 채운다. 데스크톱 16:9에서는 거의 딱 맞고, 남는 여백은 오른쪽이나 아래로 간다. 수조 안은 텅스텐빛 캐스틱 그물로 가득하다.
- 그물이 가득한 이유는 첫 페인트 전에 시뮬레이션을 2.5초 분량 미리 돌리기 때문이다(3.12).
- 수조 안의 구성은 다음과 같다.
  - 황동 점적기 2개가 ½박과 ¾박 간격으로 떨어지며 서로 다른 동심원을 만든다.
  - 왼쪽 아래 진동자(7 Hz)가 촘촘한 파열을 낸다. 이 파열이 링들과 겹쳐 쌍곡선 간섭 줄무늬가 보인다.
  - 오른쪽에는 파라핀 포물선 벽이 있어, 부딪친 링이 초점으로 모인다.
  - 가운데 렌즈 모양 유리판을 지나는 링은 찌그러진다.
- 흐릿한 율명 레인 10줄이 악보 줄처럼 깔려 있고, 라벨은 오른쪽 가장자리에 붙는다. 청동녹색 울림돌 5개 가운데 방금 맞은 것들은 램프빛 테두리가 남아 있다.
- 왼쪽 위 명판에는 `파문 투영기`가 있고, 그 아래에 `수심 6.0 mm · c 24.1 cm/s · ♩=84 · 1박=17.2 cm`가 뜬다(수치는 실측 c_eff 기준).
- 명판 바로 아래 발음 스트립에는 지난 2마디의 틱이 이미 찍혀 있다. 선행 계산 중에 생긴 발음이다.
- 왼쪽 아래 도구 레일에는 [물방울][파라핀][울림돌][장치 ▸]가 있고, 그 위에 힌트 한 줄이 있다.
- 오른쪽 아래에는 '소리 켜기' 알약 버튼과 '계기판' 탭만 있다.

### 첫 10초

- 톡 하면 다음 프레임에 그 자리에서 링이 퍼진다. 소리가 켜져 있으면 짧은 '똑' chirp가 난다.
- 링이 울림돌에 닿는 순간 돌이 번쩍이고, 스트립에 틱이 찍히고, 소리가 켜져 있으면 유리 막대 같은 음이 난다.
- 끌면 항적이 생기고 명판에 `M 0.62`가 뜬다. 빠르게 끌어 1을 넘기면 V자 원뿔이 보인다.
- 두 손가락으로 동시에 톡 하면 방울 둘이 떨어져 화음처럼 울린다.

### 1분

- 파라핀으로 벽을 그리면 링이 반사된다. 틈을 남기면 회절한다.
- 울림돌을 놓으면 높이가 음정이 되고(세로 화면에서는 오른쪽일수록 높은 음), 점적기와의 거리가 박자가 된다.
- 한 점적기에서 같은 거리에 놓은 돌들은 화음으로, 거리를 벌린 돌들은 아르페지오로 울린다.
- 돌을 끄는 동안 라벨에 '임 · 직선 1.47박'이 뜬다.

### 5분

- '장치'를 펼치면 점적기(박 나누기 1→½→⅓→¼→¾→⅔), 진동자, 유리판, 지우개를 쓸 수 있다.
- Shift 또는 `#snap-toggle`로 울림돌을 박자 링에 스냅하면 정박이 된다. 링 사이에 두면 스윙이 생긴다.
- ⅓박과 ½박 점적기를 나란히 두면 3:2 폴리리듬이 두 겹 동심원으로 교차하고, 스트립에서도 보인다.
- 수심을 천천히 올리면 도달 지연이 짧아져 위상 변이(phasing)가 생긴다.
- 유리판 뒤에 놓인 돌의 캘리퍼는 '실측 1.71박 (+16%)'처럼 직선 예측과 어긋난 값을 보여 준다.

### 15분 이후

- 프리셋 '메아리 북'에서는 원 가운데를 톡 하면 반사파가 1박마다 가운데로 다시 모인다. 라벨은 '메아리 1.00박'이다.
- '속삭이는 타원'에서는 한 초점의 점적기 소리가 다른 초점의 울림돌에만 악센트를 건다.
- '공명실'에서는 진동자 주파수를 모드에 맞추면 공명 게이지가 치솟고 바둑판 정상파가 떠오른다.
- '이중 슬릿'에서는 세로로 놓인 울림돌들의 지속음 세기가 간섭 무늬를 따라 달라진다.
- 소파 장치를 끄면 수조 전체가 잔향실이 되고 오디오 리버브도 함께 커진다.
- (P2) 스트로보를 진동자에 맞추면 무늬가 멈춘다. 배음렬 음계 + 비 모드 + 소파 끔 조합이면 저절로 흐르는 앰비언트가 된다.

## 3. 시뮬레이션 명세

### 3.1 고정 수조와 좌표 (F5 · D4)

- **수조는 64 × 36 cm로 고정한다.** 좌표는 수조 좌표 (u, v)이고 단위는 cm다. u는 오른쪽으로 0→64, v는 **위쪽**으로 0→36이다.
- **격자는 320 × 180으로 고정한다.** dx = 0.2 cm, N = 57,600셀이다.
  - 셀 (i, j)의 중심은 ((i+0.5)·dx, (j+0.5)·dx)다. 인덱스는 `i + j·320`이고 j = 0이 맨 아래 행이다.
  - 맨 바깥 1셀 테두리는 항상 벽이다(wet = 0).
- 모든 기기에서 격자가 같다. 폰에서도 세로 화면 기준 셀 하나가 약 2~3 CSS px다.
- 비상 격자(P1)만 예외로 dx = 0.25, 256×144를 쓴다(4.7).
- **레인은 10개로 고정한다.** 레인 높이는 3.6 cm이고 레인 L(0 = 가장 낮음)의 중심은 v = 1.8 + 3.6·L이다. 울림돌의 v는 항상 레인 중심이다.
- **스테레오 팬**은 pan = (u/64)·1.6 − 0.8이다. 화면 회전과 상관없이 수조 좌표로 정하므로, 같은 배치는 같은 소리가 된다.
- **뷰 변환**(수조 cm → CSS px)은 3×3 행렬 하나로 둔다.
  - 가용 영역 = 뷰포트에서 레이아웃 예약 영역을 뺀 부분(7.3).
  - 가로 모드(가용 폭/높이 > 1.05)
    - s = min(W/64, H/36)
    - X = ox + u·s, Y = oy + (36 − v)·s
    - 수조를 가용 영역의 **왼쪽 위**에 붙인다. 남는 여백은 오른쪽과 아래로 가고, 그 자리에 UI가 앉는다.
  - 세로 모드(< 0.95)
    - 시계 방향으로 90° 회전한다: X = ox + v·s, Y = oy + u·s, s = min(W/36, H/64).
    - 높은 음이 **오른쪽**, 수조의 u 축이 아래로 간다.
  - 0.95~1.05 사이는 직전 모드를 유지한다(히스테리시스).
  - 셰이더·오버레이·입력은 모두 이 행렬과 그 역행렬만 쓴다.
- **포인터 속도 환산**: v_cm = v_px / s. 척도가 수조에 고정되어 있으므로 마하수는 기기와 무관하다.

### 3.2 자료구조

```
// 격자 (Float32Array 길이 N, 비상 강등 때만 재할당)
h, hp        수면 높이(무차원), 이전 스텝 (2버퍼 교대: hp 자리에 다음 값을 쓰고 참조 교환)
kc           셀별 Courant² (유리 반영)
gm           셀별 스텝당 감쇠 γ (기본 + 소파 장치)
wet          1 = 물, 0 = 벽(바깥 테두리 포함)
glassCov     유리 덮임 0..1 (3×3 박스 평활 후)
braw         표시용 밝기 원천 (4.2)

// 벡터 저장소 (단위 cm, 되돌리기·저장·재래스터화의 원본)
walls   : [{id, pts:[u0,v0,u1,v1,...]}]   // 생성 시 0.3 cm 간격으로 재표본화
glass   : [{u, v, r, sign}]               // sign −1 = 지우개가 만든 빼기 dab. 순서대로 적용
droppers: [{id, u, v, div, nextBeat, fires: 링버퍼 64}]     // 최대 6
oscs    : [{id, u, v, f, phase}]                            // 최대 2
stones  : [{id, u, lane, 판독 상태(3.8), flashT, flashVel}]  // 최대 12
limits  : 벽 점 6,000 · 유리 dab 4,000
```

- **벽 물리 래스터**: 캔버스를 쓰지 않고, 선분 캡슐 거리 판정으로 래스터화한다.
  - 각 선분의 bounding box 안 셀 중, 중심에서 선분까지 거리가 **0.9셀(0.18 cm) 이하**이면 벽으로 만든다.
  - 벽 두께는 1.8셀로 √2셀 이상이므로, 어떤 각도에서든 4-연결 벽이 되어 9점 스텐실에서 새지 않는다.
  - 새로 벽이 된 셀은 h = hp = 0으로 둔다.
- **유리 물리 래스터**: dab을 순서대로 적용한다(원 안 셀을 sign+이면 1, sign−이면 0으로). 결과를 3×3 박스로 평활해 glassCov를 만든다.
- **표시용 마스크**: 오프스크린 Canvas2D 두 장(640×360, 10 px/cm)을 쓴다. 벽 캔버스에는 흰 스트로크(폭 3.6 px, round cap/join)를, 유리 캔버스에는 흰 원을 그린다. 빼기 dab은 `destination-out`으로 지운다. 두 캔버스를 각각 R8 텍스처로 올린다(4.3).
- **증분 갱신**: 그리는 중에는 새 선분·dab만 물리 래스터에 반영한다. 영향받은 셀의 kc·gm·wet을 갱신하고, 표시 마스크 업로드는 최대 30 Hz로 제한한다. 지우기·되돌리기·프리셋 로드는 전체를 다시 만든다. N이 작아서 전체 재구성은 수 ms면 끝난다.

### 3.3 시간: 단일 시계 (F3 · D1)

- **시뮬 시간 `simTime`(초)이 유일한 마스터 시계다.**
  - transport(박 위치)는 매 스텝 `beatPos += dt·BPM/60`으로 시뮬에서 파생한다.
  - 점적기, 판독, 발음 스트립, 오디오 스케줄은 모두 simTime을 기준으로 한다.
- **고정 스텝**: `dt = C·dx / c_deep`, C = 0.55(고정 Courant 수), c_deep = √(g·d), g = 981 cm/s².
  - 기본 d = 0.60 cm이면 c = 24.26 cm/s, dt = 4.53 ms, 초당 220 스텝이다.
  - d = 0.30이면 초당 156 스텝, d = 1.20이면 312 스텝이다.
- **수심을 바꾸면** dt가 바뀐다. 내재 속도를 보존하려고 `hp = h − (h − hp)·(dt_new/dt_old)`로 한 번 보정하고, gm(기본 감쇠)을 다시 계산한다.

**프레임 루프 의사코드**
```
frame(now):
  wallDt = clamp(now − lastNow, 0, 0.100); lastNow = now
  if paused: renderOnly(); return
  acc += wallDt × timeScale                    // timeScale: 1, 감쇠 모드 0.4
  need = floor(acc / dt)
  maxSteps = max(1, floor(SIM_BUDGET_MS / stepCostEMA))   // 데스크톱 6 ms, 폰 9 ms
  n = min(need, maxSteps)
  if need > n: acc −= (need − n)·dt           // 못 따라간 몫은 버린다 → 전역 시간 팽창
  repeat n: step()                             // 이벤트는 정확한 simTime 도장을 받음
  acc −= n·dt
  dilation = EMA_1s( n·dt / (wallDt·timeScale) )   // < 0.97이면 명판에 "시간 ×0.82"
  scheduleAudio(frameEvents)                   // 아래 사상식
  updateVisualState(); render()
```

- 점적기도 simTime에서 파생한 beatPos로 발사하므로, 시간이 팽창해도 리듬은 서로 어긋나지 않고 전체가 함께 느려진다.
- **오디오 사상** (소리가 켜져 있을 때)
  - `rate = timeScale × dilation`
  - `LOOKAHEAD = clamp(1.3 × 프레임간격EMA, 0.03, 0.08)` s
  - 프레임 끝의 simTime을 t1이라 하면, 이상적인 대응은 `ideal = ctx.currentTime + LOOKAHEAD`다.
  - 현재 사상 `mapped = audioAnchor + (t1 − simAnchor)/rate`와 비교해, |mapped − ideal| > 0.05 s이거나 rate가 2% 넘게 변했으면 `simAnchor = t1, audioAnchor = ideal`로 **재고정**한다.
  - 이벤트 시각은 `when = audioAnchor + (ev.t − simAnchor)/rate`로 구하고, `max(when, ctx.currentTime + 0.005)`로 하한을 둔다.
- **탭 복귀**: `lastNow = now`, `acc = 0`으로 둔다. 소리가 켜져 있으면 resume한 뒤 첫 프레임에서 재고정한다. 쌓인 시간을 따라잡는 몰아치기는 하지 않는다.
- **탭 입력**은 다음 프레임의 첫 스텝에 주입한다. 지연은 최대 1프레임이다.

### 3.4 파동 방정식과 이산화

- 모델은 선형 얕은 물 파동 `h_tt = c(x)²∇²h − 2β·h_t`다.
- 9점 등방 라플라시안(셀 단위):
  `L = (4(hN+hS+hE+hW) + (hNE+hNW+hSE+hSW) − 20h) / 6`
- 갱신(내부 셀 전체를 도는 단일 평탄 루프, 벽은 곱셈으로 처리해 분기를 없앤다):
  ```
  a  = |h| − H_SAT
  γ  = gm[i] + (a > 0 ? B_NL·a : 0)          // 진폭 의존 포화 감쇠 (F1)
  hn = (h + (1 − γ)(h − hp) + kc[i]·L) · wet[i]
  ```
- `kc[i] = C²·(1 − 0.65·glassCov[i])`
  - 깊은 물은 C² = 0.3025다. 이 스텐실의 안정 한계 0.75, 목표 상한 0.45 안에 있다.
  - 유리판은 유효 수심 0.35·d이므로 kc = 0.106이고, c가 0.59배가 되어 굴절률 n ≈ 1.69다.
- `gm[i] = min(0.35, 2·β·dt + γ_beach[i])`
  - β(진폭 감쇠율)는 기본 0.12/s, 범위 0.04~0.50/s다.
  - 소파 장치가 켜져 있으면 `γ_beach = 0.25·((14 − e)/14)²`이고, e는 바깥 테두리로부터의 셀 거리(< 14)다. 폭은 2.8 cm이고 램프형이라 경계에서 반사가 거의 없다.
  - 소파 장치를 끄면 γ_beach = 0이 되어 테두리가 유리벽처럼 반사한다.
- 벽은 디리클레 경계(h = 0)다. 반사파의 위상이 뒤집히지만 도달 시각은 같다. 교육용 단순화이며 정보 문구에는 쓰지 않는다.

### 3.5 소스

| 소스 | 주입 | 기본값 |
|---|---|---|
| **물방울**(탭·점적기·비) | 멕시칸햇을 **h와 hp에 똑같이** 더한다(정지 상태에서 놓은 변위라서 깨끗한 단일 링이 된다): `A·(e^(−r²/2σ²) − 0.25·e^(−r²/8σ²))`. 적분이 0이라 DC가 없다. 적용 반경은 6σ, 벽 셀은 건너뛴다 | 탭 A = 1.0, 점적기 0.85, 비 0.55. σ: 탭·점적기 2.2셀, 비 2.0셀. **σ 하한 1.8셀**(D3) |
| **끌기 항적** | 매 스텝, 이번 프레임의 포인터 선분을 스텝 수로 나눈 위치들에서 `h −= P_w·dt·min(1, v/c_eff)·e^(−r²/(2·1.6²))`(반경 5셀). 한 스텝 이동이 1셀을 넘으면 최대 8회까지 나눠 찍는다. hp는 건드리지 않는다 | P_w = 25 /s (튜닝) |
| **진동자** | 매 스텝 `h += Q·g_auto·dt·sin(2πf·t + φ)·e^(−r²/(2·1.5²))`(반경 5셀) | Q = 12 /s (튜닝: 5 cm 떨어진 곳의 진폭이 약 0.08). f 범위는 3.00 ~ min(14, c_eff/(8·dx)) Hz, 기본 7.00 |
| **점적기** | beatPos가 nextBeat를 넘는 스텝에서 발사한다. 발사 시각은 스텝 안에서 선형 보간해 정확한 simTime으로 기록하고, `nextBeat += div`. 배치하거나 옮길 때는 `anchor = round(beatPos·4)/4`로 16분음표에 스냅한 뒤 beatPos보다 커질 때까지 div를 더한다 | div ∈ {1, ½, ⅓, ¼, ¾, ⅔}. 탭할 때마다 이 순서로 순환 |
| **비** | 프레임마다 Poisson(λ·Δt_sim)개의 방울을 만든다. 위치는 소파 장치 안쪽 1 cm의 무작위 물 셀, 스텝 시각은 무작위 | 입력이 12초 없으면 λ = 0.45/s, 비 모드(W, P1)는 4/s. 감쇠 모드에서는 자동 비를 끈다 |

- 마하수는 `M = v_sim / c_eff`다. `v_sim = v_cm / rate`이고, 80 ms EMA로 평활한다. 물 손가락으로 끄는 동안 명판에 `M 1.34`로 표시하고, 손을 뗀 뒤 1.5초에 걸쳐 사라진다.

### 3.6 수치 안정성 장치 (F1)

1. Courant 수를 0.55로 고정한다. 어떤 수심에서도 kc ≤ 0.3025여서 한계 0.75에 여유가 크다.
2. 진폭 의존 포화 감쇠: H_SAT = 1.2, B_NL = 0.02 (튜닝). 공명실이나 소파를 끈 상태에서도 부드럽게 포화한다.
3. **에너지 E와 자동 게인**
   - 4프레임마다 `E = mean_water(h² + ((h − hp)/0.216)²)`를 계산한다. 0.216 = C·(2π/16)이며, 파장이 16셀인 파에서 E ≈ 진폭²이 되게 하는 정규화다.
   - E > E_SOFT(0.20, 튜닝)이면 진동자 게인에 매 프레임 `g_auto ×= 0.97`을 곱한다(하한 0.15). 그렇지 않으면 `g_auto += (1 − g_auto)·0.01`로 회복시킨다.
   - 공명 게이지(P1)는 log10(E)를 −5~0 구간에서 표시한다.
4. DC 제거: 60프레임마다 물 셀 평균 m을 구해 h와 hp에서 각각 0.5m을 뺀다.
5. **하드 리셋은 NaN/Inf를 감지했을 때만 한다.** 30프레임마다 7칸 간격 표본의 합이 유한한지 검사한다. 비정상이면 h = hp = 0으로 두고 토스트 "수면이 넘쳐 잠재웠습니다"를 띄운다.
6. 한 프레임의 벽시계 간격은 100 ms로 자르고, 스텝 수는 예산으로 상한을 둔다(3.3).
7. 소스 세기를 제한한다. 항적은 min(1, v/c), 방울 A ≤ 1.0이다.
8. γ ≤ 0.35로 클램프한다.

### 3.7 c_eff 실측 보정 (D3)

- 부팅 때 선행 계산 전에 딱 한 번 하고, 비상 격자로 강등할 때 다시 한다. Courant 수가 고정이므로 비율 ρ = c_eff/c는 수심과 무관하다.
  ```
  scratch 격자 180×180 (같은 dx, C = 0.55, γ = 0, 소파 없음, 테두리만 벽)
  중앙에 멕시칸햇 A = 1, σ = 2.2
  탐침 r1 = 25셀, r2 = 70셀 (+u 방향과 −v 방향 두 개씩, 평균)
  t > (r2 + 20)·dx/c 가 될 때까지 진행; 첫 통과 창에서 |x| 최대 시각 t1, t2와 진폭 p1, p2 기록
  c_eff = (r2 − r1)·dx / (t2 − t1);   RHO = c_eff / c
  n = ln(p1/p2) / ln(r2/r1)                          // 확산 지수 ≈ 0.5
  p_far = p2 · (r2/300)^n · e^(−β·(300·dx)/c_eff)    // 60 cm 먼 구석
  THETA_FLOOR = clamp(0.35 · 0.85 · p_far, 0.006, 0.03)   // β를 바꾸면 이 식만 다시 계산
  ```
- 비용은 약 530만 셀 갱신이다. 데스크톱 약 12 ms, 폰 약 50 ms.
- **이후 모든 박자 관련 표시와 계산에 `c_eff = RHO·√(g·d)`를 쓴다.** 명판 c, 1박 거리, 박자 링, 스냅, 지연 라벨, 메아리 라벨, 프리셋 반지름, 진동자 f 상한이 모두 해당한다.

### 3.8 울림돌 판독 (F2 · D2)

매 스텝 각 울림돌 위치에서 h를 bilinear로 샘플해 x를 얻고 아래 절차를 돈다.
```
a = |x|
ef  = max(a, ef·exp(−dt/0.035))            // 빠른 포락선(피크 홀드)
es += (a − es)·(dt/0.40)                   // 느린 평균 포락선
rms2 += (x² − rms2)·(dt/0.25)              // 지속음용
thr = max(THETA_FLOOR, K_ON·es)            // K_ON = 2.2 (튜닝)

IDLE:    a > thr                 → RISING (peak = a, tPeak = t, tStart = t)
RISING:  a > peak                → peak = a, tPeak = t
         a < 0.8·peak 또는 t − tStart > 0.06
                                 → 발음(tPeak, vel), REFRACT (tFire = tPeak, lastPeak = peak)
REFRACT: t − tFire ≥ 0.070 이고 ef < max(thr, 0.35·lastPeak) → IDLE
vel = clamp((peak − 0.5·es) / A_REF, 0.06, 1),   A_REF = 0.25 (튜닝)
```
- **진동자 연속파**: 정상 상태에서 es ≈ 0.64·진폭, ef ≈ 진폭이므로 thr ≈ 1.4·진폭이 되어 타격이 나지 않는다. 연속 성분은 지속음 경로(rms)로만 간다. 그 위에 진동자 진폭의 약 0.4배를 넘는 방울 링이 겹칠 때만 타격한다.
- **지속음 게인**(P1, 진동자가 1개 이상일 때): `clamp((√rms2 − 0.02)·3, 0, 0.5)`. 간섭 마디선에서는 실제로 0에 가까워진다.
- 발음 이벤트는 `{type: 'strike', t: tPeak, stone, lane, u, vel}`이며, 다음 네 곳에 쓰인다.
  - 번쩍임 상태(flashT, flashVel)
  - 발음 스트립
  - 캘리퍼 기록
  - 오디오(소리가 켜져 있을 때)
- 선행 계산 중에 난 발음도 번쩍임과 스트립에는 기록한다. 오디오에는 보내지 않는다.

### 3.10 박자 기하

- **박자 링**(P1)
  - 반지름은 `r_n = c_eff·n·(60/BPM)/4`(n = 1..16, 16분음표 간격)이다. 4번째마다 굵게 그린다.
  - 표시하는 때
    - 울림돌을 끄는 동안: 모든 점적기 둘레
    - 점적기를 끄는 동안: 그 점적기 둘레
    - `#grid-toggle`이 켜져 있으면: 항상
  - 링 옆에 작게 '직선 기준'이라고 적는다.
- **지연 라벨**(P0)
  - 울림돌을 끌거나 선택하면 기준 점적기(직선거리가 가장 가까운 것)로부터의 `d/c_eff·BPM/60`을 표시한다. 예: `임 · 직선 1.47박`.
  - 점적기가 없으면 음명만 표시한다.
- **박자 스냅**(P1, Shift를 누르는 동안 또는 `#snap-toggle`)
  - 울림돌의 레인(v)은 유지한 채, 기준 점적기로부터의 거리가 가장 가까운 r_n이 되도록 u를 푼다: `u = u_d ± √(r_n² − (v − v_d)²)`. 부호는 돌이 있던 쪽이다.
  - 해가 없는 n은 건너뛴다.
- **캘리퍼**(P1, 채택 graft)
  - 점적기마다 최근 64회의 발사 시각을 기록한다.
  - 울림돌이 발음하면, 기준 점적기의 발사 가운데 `(onset − fire)`가 [0.5·예측, 2.0·예측] 범위에 있고 예측과 가장 가까운 것을 짝으로 고른다.
  - 최근 3회 짝의 평균을 '실측'으로 둔다.
  - 라벨: `임 · 직선 1.47박 · 실측 1.71박 (+16%)`. 짝이 2회 미만이면 `실측 —`를 표시한다.
  - |차이| > div/2이면 어느 발사의 도달인지 모호하므로 값 앞에 `≈`를 붙인다.
- **메아리 라벨**(P1)
  - 파라핀 획을 끝냈을 때 다음 조건이면 원으로 판정한다.
    - 점이 12개 이상
    - 끝점 사이 거리 < 총 길이의 6%
    - 반경 표준편차 / 평균 < 0.12 (중심은 점 평균, 반경은 평균 거리 R)
  - 원이면 끝점을 이어 닫고, 원 위쪽에 `메아리 {2(R − 0.18)/c_eff·BPM/60 :.2f}박`을 붙인다. 템포나 수심이 바뀌면 라벨을 다시 계산한다.

## 4. 렌더링 명세

### 4.1 층 구성 (아래에서 위로)

1. `#gl` WebGL2 캔버스: 투영면 전체를 그린다. 수조 밖의 투영지와 수조 테두리 그림자도 여기서 그린다. `pointer-events: none`.
2. `#fallback` Canvas2D: 폴백일 때만 보인다.
3. `#stage` 오버레이 Canvas2D: 글리프와 라벨을 그리고 **모든 포인터 입력을 받는다**. `tabindex=0`, `role="application"`, `touch-action: none`.
4. DOM UI: 명판, 발음 스트립 캔버스, 도구 레일, 계기판, 토스트.

선택 근거: 판독을 스텝 단위로 해야 하므로 솔버는 CPU에 있어야 한다(readPixels 스톨 없음). 투영만 GPU가 맡는다. 상태가 CPU에 있으므로 폴백과 컨텍스트 소실을 처리해도 음악과 상태가 끊기지 않는다.

### 4.2 CPU 표시 원천 `braw` (F4 · D5)

- 표시하는 프레임마다(스트로보 중에는 샘플 시각에만) 격자 해상도로 계산한다.
  ```
  L  = 9점 라플라시안(h)                           // 셀 단위
  gx = (hE − hW)/2,  gy = (hN − hS)/2
  S  = −(gx·ℓu + gy·ℓv)                           // ℓ = normalize(−0.6, 0.8): 램프 쪽 방향
                                                  //   (가로 화면 기준 왼쪽 위). 램프를 향한 사면이 밝다
  braw = −κ·L + σs·S,     κ = 12, σs = 0.75 (튜닝)
  ```
- 벽 셀은 braw = 0이다.
- 곡률과 기울기를 격자 해상도에서 한 채널로 합치므로, 셀 경계에 미분이 몰리는 마름모 격자 무늬가 원천적으로 생기지 않는다.
- **'격자보다 가는 캐스틱'은 목표가 아니다.** 부드러운 빛 띠를 LUT의 soft clip으로 조여 캐스틱처럼 보이게 한다.
- **튜닝 목표**(수용 기준 연동): 첫 장면에서 수조 픽셀의 **8~18%가 B ≥ 0.70**(텅스텐 구간), **45~70%가 B ≤ 0.50**(청록 구간)이어야 한다.

### 4.3 GL 자원

- `fieldTex`와 `fieldPrevTex`(스트로보 크로스페이드용): **R16F**, 320×180, LINEAR, CLAMP. `texSubImage2D(…, RED, FLOAT, braw)`로 올린다. R16F + FLOAT 업로드는 WebGL2 코어에서 유효하고 필터링도 된다.
- `wallTex`와 `glassTex`: R8, 640×360. 오프스크린 캔버스에서 `texImage2D(R8, RED, UNSIGNED_BYTE, canvas)`로 올린다. 기하가 바뀔 때만, 최대 30 Hz로 올린다.
- `lutTex`: 256×1 RGBA8, LINEAR.
- 풀스크린 삼각형 1개, 프로그램 1개.

### 4.4 프래그먼트 셰이더

1. 화면 좌표(CSS px)에 `uScreenToTank` 역행렬을 곱해 수조 좌표 (u, v)를 얻는다.
2. **수조 밖(투영지)**
   - B = 0.40 + 정적 해시 노이즈 ±0.6%로 둔다.
   - 수조 가장자리 바깥 0.8 cm까지는 테두리 그림자로 0.35배까지 어둡게 한다.
   - 램프 비네팅을 적용한다.
3. **수조 안**
   - 텍셀 좌표 = (u, v)/dx − 0.5.
   - **4탭 B-스플라인 바이큐빅**을 쓴다. 텍셀 좌표 x에서 i = floor(x), f = x − i로 두고:
     - w0 = (1−f)³/6, w1 = (3f³ − 6f² + 4)/6, w2 = (−3f³ + 3f² + 3f + 1)/6, w3 = f³/6
     - g0 = w0 + w1, g1 = w2 + w3
     - 오프셋 h0 = w1/g0 − 1, h1 = w3/g1 + 1
     - 샘플 위치 (i + h + 0.5)/size, 2D로 bilinear 4탭을 g 가중합한다.
   - 채널별 분산: G는 중심에서, R은 **+0.35 텍셀·ℓ**, B는 **−0.35 텍셀·ℓ** 오프셋에서 각각 bicubic으로 샘플한다(12탭). 저품질 단계에서는 중심 하나만(4탭).
   - `B_c = 0.46 + uContrast · braw_c`. 채널마다 LUT(B_c)에서 해당 채널만 가져온다.
   - **유리**: `gc = glassTex`. `mix(col, #6FA596, 0.08·smoothstep(0.3, 0.7, gc))`에 가장자리선 `(1 − smoothstep(0, 0.12, |gc − 0.5|))·0.12·#9CC9BC`를 더한다.
   - **벽**
     - `wc = wallTex`, `α = smoothstep(0.35, 0.65, wc)`.
     - 베벨 법선은 dFdx/dFdy(wc)로 구하고, 파라핀 음영 = `#D9D3BF·(0.80 + 0.20·dot(−n̂, ℓ))`.
     - 경계 α 0.35~0.5 구간은 한 톤 어둡게 해 밀랍 테두리를 만든다.
     - 그림자: `ws = wallTex(uv − ℓ·0.30 cm)`, `col ×= 1 − 0.40·ws·(1 − α)`.
   - **소파 장치**(켜졌을 때만): 가장자리 2.8 cm 띠에 45° 철망 선(fract 기반, #0C1D1F 6%)을 깐다.
   - 수조 안쪽 가장자리 0.3 cm는 유리 수조 테두리로 어둡게 한다.
4. **램프 원뿔 비네팅**: `col ×= 1 − 0.18·smoothstep(0.3, 1.1, 수조 중심 거리 / 반대각선)`.
5. 스트로보 크로스페이드: `mix(prev, cur, uHoldMix)` (4.9).

### 4.6 오버레이 (Canvas2D, F8)

  - **점적기**: 황동 물방울 모양 14 px, 옆에 박 분할 라벨(Plex Mono 10 px, `½박`). 발사할 때 황동 링이 펄스한다(감쇠 모드에서는 글리프 밝기만 바뀐다).
  - **진동자**: 청동녹 링과 황동 중심 핀, 라벨 `7.00 Hz`. 주파수로 깜박이는 애니메이션은 넣지 않는다.
  - **울림돌**: 반지름 max(0.45 cm·s, 9 px). 방사 그라데이션 #6FA596 → #3E6B61.
    - 발음하면 램프빛 테두리(#F3DCA2)를 그린다. 알파 = vel·e^(−age/0.25 s).
    - 확장 링은 0 → 1.2 cm, 0.3 s, 알파 0.5·vel. 감쇠 모드에서는 링 없이 페이드만.
  - 선택: 황동 점선 원. 길게 누르기 진행: 황동 호(150 ms부터 550 ms까지).
  - 박자 링과 지연·캘리퍼·메아리 라벨: Plex Mono 11 px, 반투명 #0C1D1F 받침.
  - 키보드 조준경: 황동 1 px 십자, 가운데 틈 4 px. 캔버스가 키보드로 포커스되었을 때만 보인다.
  - (P2) 손짓 루프의 유령 궤적: 황동 25%.
- **발음 스트립** `#strip`(채택 graft, P0)
  - 크기: 데스크톱 280×64 px, 폰 세로 화면은 가로 전폭 − 32 px × 30 px. DPR 적용.
  - 가로축은 최근 8박으로, 오른쪽이 현재다. 1박마다 옅은 세로선, 4박마다 황동 세로선.
  - 행은 레인 10개(아래가 낮은 음)다. 발음 틱은 폭 2 px 청동녹, 알파 = vel이다. 가장 최근 틱은 250 ms 동안 텅스텐색.
  - 맨 위 1 px 기준선에 점적기 발사를 황동 점으로 찍는다.
  - 무음일 때도 그린다. 감쇠 모드에서는 연속 스크롤 대신 1박 단위로 갱신한다.
  - `role="img"`, `aria-label="최근 두 마디 발음 기록"`.

### 4.7 DPR과 품질 자동 조절

- `#gl` 백버퍼 = CSS 크기 × min(dpr, 1.5) × renderScale. `#stage`와 `#strip`은 min(dpr, 2).
- 프레임 시간 EMA(α = 0.1)로 단계를 오르내린다. EMA가 20 ms를 2초 넘기면 한 단계 내리고, 12 ms 미만이 5초 이어지면 한 단계 올린다. 단계 변경은 5초에 한 번까지다.
  - 단계 0: renderScale 1.0, 색 분산 켬
  - 단계 1: 0.75
  - 단계 2: 0.6, 색 분산 끔(4탭), 박자 링은 굵은 것만
- **CPU 과부하**는 시간 팽창(3.3)이 먼저 흡수한다.
- 단계 2에서도 dilation EMA < 0.85가 3초 이어지면 **비상 격자 강등**(P1)을 한다.
  - dx = 0.25, 256×144로 바꾼다.
  - h와 hp를 bilinear로 리샘플한다.
  - 벡터에서 다시 래스터화한다.
  - c_eff를 다시 보정한다.
  - 명판에 `저사양 격자`를 표시한다. 한 세션에서 다시 올라가지는 않는다.

### 4.8 폴백과 컨텍스트 소실 (F6)

- **부팅 검사**: WebGL2 컨텍스트가 있는지, R16F 텍스처를 만들고 FLOAT로 texSubImage2D한 뒤 `gl.getError() === NO_ERROR`인지, 셰이더 컴파일·링크가 성공하는지 본다. 하나라도 실패하면 폴백으로 간다.
- **Canvas2D 폴백**
  - 320×180 ImageData에 braw → B → 같은 LUT로 색을 채운다(색 분산 없음).
  - 벽·유리는 물리 래스터 값으로 셀 색을 섞는다(벽 #D9D3BF, 유리 8% 틴트).
  - 뷰 행렬로 setTransform(회전 포함)한 뒤 `imageSmoothingQuality = 'high'`로 확대한다.
  - 명판 둘째 줄에 `간이 투영 모드`를 표시한다.
- **컨텍스트 소실**
  - `webglcontextlost`에서 preventDefault하고 즉시 `#fallback`을 표시한다. 시뮬과 오디오는 계속 돈다.
  - `webglcontextrestored`에서 텍스처·LUT·프로그램을 다시 만들고 GL로 돌아간다.
  - 3초 안에 복구되지 않으면 그 세션은 폴백으로 유지한다.

### 4.9 스트로보 (P2, F9 · D6)

- **기본은 끔**이다. 처음 켤 때 토스트와 aria-live로 안내한다: "스트로보는 물결 무늬를 끊어 보여 줍니다. 빛에 민감하면 끄세요."
- 시뮬은 계속 돌리고, `braw` 계산과 업로드만 simTime 기준 1/f_s 간격으로 한다. 어두운 점멸은 없다.
- 홀드가 바뀔 때마다 이전 텍스처와 새 텍스처를 **70 ms 크로스페이드**한다(uHoldMix).
- f_s > 3 Hz이면 두 홀드 사이 평균 |Δbraw|(16칸마다 표본) D를 잰다. D > 0.08이면 `uContrast ×= max(0.4, 0.08/D)`.
- f_s 범위는 1~15 Hz이고 `[` `]`로 ±0.05 Hz씩 바꾼다. `#strobe-match`는 f_s를 선택된(또는 첫) 진동자의 f로 맞춘다.
- 감쇠 모드에서는 스트로보를 비활성으로 두고 컨트롤을 disabled로 만든다. 사유는 aria-describedby로 알린다.

### 4.10 전역 광과민 안전

- 매 프레임 braw 표본의 평균 |braw| = m을 구한다. 대비 목표는 `min(1, 0.14/m)`이고, τ = 0.5 s로 평활해 `uContrast`에 곱한다(하한 0.45).
- 비 모드, 대량 탭, 공명 상황에서 화면 전체 밝기가 크게 출렁이지 않게 하려는 장치다.
- 감쇠 모드에서는 여기에 κ × 0.6을 추가로 곱한다.

### 5.1 포인터 판정 규칙 (F7 · D7) — 단일 규칙

|---|---|

- 두 손가락 핀치나 줌은 없다. 페이지 확대는 캔버스의 `touch-action: none`으로 막는다.
- 스냅은 **Shift 또는 `#snap-toggle`**, 유리 붓 크기는 **`#brush-size` 또는 휠**이 맡는다. 두 번째 손가락에는 '물' 외의 의미가 없다.
- `pointercancel`이 오면 진행 중인 획을 그대로 확정한다.

- 기록이 끝나면 8박마다 영원히 재생한다. 최대 3층까지 쌓인다.

## 6. 사운드 명세

- **기본은 무음이다.** `#sound-toggle` 클릭(또는 M 키) 핸들러 안에서 동기적으로 AudioContext를 만들고 `resume()`을 호출한 뒤 그래프를 만든다.
- 생성에 실패하면 버튼을 `소리를 켤 수 없음`으로 바꾸고 disabled로 만든 뒤 aria-live로 알린다.
- 끌 때는 마스터 게인을 0.1 s 동안 0으로 내린 뒤 `suspend()`한다.
- 터치 기기에서는 버튼 아래에 한 줄을 둔다: "소리가 안 들리면 기기의 무음 스위치를 확인하세요".
- **시계**: 모든 발음 시각은 3.3의 사상식으로 스케줄한다.

**마스터 체인**
```
dryBus ─┐
        ├─► DynamicsCompressor(threshold −18 dB, knee 6, ratio 4, attack 5 ms, release 150 ms)
wetBus ─┘        ─► masterGain(= volume/100, 기본 0.70, 상한 1.0) ─► destination
reverbSend ─► ConvolverNode(절차 IR) ─► wetGain ─► wetBus
```
- 잔향 IR: 스테레오 2.4 s, L과 R에 독립 백색잡음 × e^(−t/0.45). 소리를 켤 때 한 번 생성한다.
- wetGain은 소파 장치가 켜져 있으면 0.18, 꺼져 있으면 0.38이다(setTargetAtTime τ 0.3). 시각의 반사율과 청각의 잔향을 묶는다.

**울림돌 타격 (P0) — 자유단 막대 모달 합성**
- 부분음: 사인 3개, 비율 1 : 2.756 : 5.404, 게인 1 : 0.28 : 0.09.
- 피크 게인은 `0.25·vel^1.2`다.
- 엔벨로프: 3 ms 선형 어택 뒤 `setTargetAtTime(0, t + 0.003, τ_k)`. τ = (0.9, 0.3, 0.1) s × (0.6 + 0.4·vel).
- 물 닿는 클릭: 공유 백색잡음 버퍼 → bandpass(fc = min(4·f0, 8000), Q 8) → 15 ms 감쇠, 게인 0.12·vel.
- StereoPanner로 팬을 준다(3.1). reverbSend는 0.6.
- 보이스는 `t + 5·τ1`(≤ 4.5 s)에 stop한다.

**물방울 소리 (P0) — 민나르트 공명**
- 사인 chirp다. f0 = 3260/R Hz이고 R은 0.9~1.6 mm에서 무작위로 뽑는다(2.0~3.6 kHz).
- 30 ms 동안 exponentialRamp로 1.4·f0까지 올린다.
- 게인은 2 ms 어택 뒤 τ 12 ms로 감쇠한다. 탭 0.05, 점적기 0.03, 비 0.02.
- 초당 12회 상한, reverbSend 0.3.

**지속음 (P1)**
- 진동자가 1개 이상 있을 때, 울림돌마다 사인 2개(f0과 f0·1.004) → lowpass 1.8 kHz → 게인 → 팬으로 보이스를 둔다.
- 게인은 3.8의 지속음 게인 × 0.6을 따른다(setTargetAtTime τ 0.05).
- 게인이 2초 동안 0.003 미만이거나 진동자가 없어지면 stop하고 해제한다.

**진동자 허밍 (P1)**
- f×32 삼각파(0.6) + 사인(0.4) → lowpass 900 Hz → 게인 `0.06·g_auto` → 팬.
- 주파수 변화는 setTargetAtTime τ 0.03으로 따라간다. 두 진동자의 주파수가 다르면 서로 맥놀이한다.

**스트로보 틱 (P2)**: f_s ≤ 8 Hz일 때만 3 ms 잡음을 highpass 2 kHz로 거르고 게인 0.03으로 낸다.

**안전 상한**
- 타격과 물방울 보이스는 합쳐 동시 28개다. 초과하면 가장 오래된 보이스를 10 ms 릴리스로 훔친다.
- 지속음은 12개, 허밍은 2개를 따로 센다.
- 타격 트리거는 초당 40개(토큰 버킷)다. 울림돌별 불응기는 70 ms다(3.8).
- 탭이 숨겨지면 `ctx.suspend()`, 돌아오면 소리가 켜져 있던 경우에만 `resume()`한다.

### 7.4 테마 전략

투영면은 의도적인 단일 암실 테마다. 캐스틱 대비가 곧 작품의 정체성이기 때문이다. 명판·스트립 배경·도구 레일·계기판 같은 UI 크롬만 라이트와 다크로 바뀐다(7.1).

### 7.5 컨트롤 형태

- **슬라이더**: 트랙 2 px(`--line` 두 배 농도), 채움 `--accent`, 썸 14×14 px(radius 3, 황동). 수치는 오른쪽 정렬 모노로 표시한다.
- **스위치**: 30×16 각진 캡슐(radius 3). 켜지면 황동으로 채운다.
- **select**: 1 px 테두리, radius 2.
- 계기판 안 버튼은 radius 2 평면이고, 소리 버튼만 알약형이다. 명판·계기판·탭·알약의 radius와 그림자는 모두 다르게 한다.

### 7.6 모션 원칙

- UI 전환은 160~220 ms ease-out, 바운스 없음. 패널은 translate + opacity로 연다.
- 캔버스 안의 움직임은 전부 시뮬 시간이 만든다. 장식용 루프 애니메이션은 넣지 않는다.
- 초당 3회 넘게 명멸하는 UI 요소를 만들지 않는다. 진동자 글리프는 정지해 있고, 울림돌 번쩍임은 감쇠형이다.
- 감쇠 모드에서는 CSS transition을 0으로 한다.

## 8. 접근성·견고성

- **움직임 감쇠 모드**(`prefers-reduced-motion` 또는 `#motion-toggle`, 실행 중에도 전환 가능)
  - timeScale 0.4, κ × 0.6, 자동 비 끔, 스트로보 비활성.
  - 울림돌은 확장 링 없이 페이드만, 점적기 펄스 없음, 스트립은 박 단위 갱신.
  - 첫 장면은 감쇠 변형(점적기 B 하나, 1박, 진동자 없음)으로 로드한다. 이미 사용자가 놓은 오브젝트는 건드리지 않는다.
  - 모든 상호작용은 그대로 쓸 수 있다.
- **포커스**
  - 모든 컨트롤에 `:focus-visible { outline: 2px solid var(--focus); outline-offset: 2px }`를 준다.
  - 캔버스가 포커스되면 수조 테두리 안쪽에 2 px 황동 링과 조준경을 그린다.
  - Tab 순서: 캔버스 → 도구 → 장치 → 소리 → 계기판 → 계기판 내부.
  - 캔버스: `role="application"`, `aria-label="물결통 투영면. 화살표로 조준경을 옮기고 Enter로 현재 도구를 씁니다. 1~7로 도구를 고릅니다."`
- **탭 숨김**: `visibilitychange`로 숨겨지면 rAF를 취소하고 오디오를 suspend한다. 돌아오면 3.3의 복귀 규칙을 따른다.
- **리사이즈와 회전**
  - #stage에 ResizeObserver를 걸고 150 ms 디바운스한다.
  - 다시 하는 일: 뷰 행렬 재계산(가로·세로 판정), 캔버스 크기 조정, 정적 레이어 다시 그리기.
  - **격자와 파동장은 건드리지 않는다.** 수조가 고정이므로 오브젝트와 벽의 관계, 음정, 박자가 모두 보존된다.

  - 키 `pamun-tank-v1`에 JSON {walls, glass, droppers, oscs, stones, bpm, depth, scale, beach}를 저장한다.
  - 변경 후 1 s 디바운스로 저장하고, 읽기·쓰기는 모두 try/catch한다.
  - 볼륨, 음계, 움직임 설정은 `pamun-prefs-v1`에 따로 둔다. 소리 켜짐 여부는 저장하지 않는다.
  - 로드 때 자동 적용하지 않는다. `#preset`에 '내 수조'가 생기고, 명판 힌트에 "지난 수조: 프리셋 › 내 수조"를 한 번 보여 준다.
- **사용자에게 보이는 폴백·에러 메시지**

| 상황 | 표시 위치 | 문구 |
|---|---|---|
| WebGL2 없음 또는 R16F 실패 | 명판 | `간이 투영 모드` |
| 컨텍스트 소실 | 토스트 | "투영기를 다시 켜는 중…" (복구 실패 시 간이 모드 유지) |
| 오디오 실패 | 버튼 + aria-live | "소리를 켤 수 없음" |
| NaN/Inf | 토스트 | "수면이 넘쳐 잠재웠습니다" |
| 오브젝트 상한 | 토스트 | "울림돌은 12개까지" 등 |
| 벽 위 배치 | 토스트 | "벽 위에는 놓을 수 없어요" |
| 시간 팽창 | 명판 | `시간 ×0.82` |
| 비상 격자 | 명판 | `저사양 격자` |

- 폰트 로드 실패는 알리지 않고 fallback 폰트로 둔다.

## 9. 수용 기준

1. **첫 프레임**: 데스크톱에서 스크립트 시작 1.5 s 안에 첫 페인트가 나온다. 빈 캔버스나 "클릭하세요" 화면 없이, 첫 정지 프레임에 3.12의 첫 장면 구성과 이미 틱이 찍힌 스트립이 보인다.
2. **캐스틱 톤**: 첫 장면에서 수조 픽셀의 8~18%가 B ≥ 0.70, 45~70%가 B ≤ 0.50이다. 셀 경계를 따라 마름모 격자 무늬가 보이지 않는다(데스크톱에서 셀 약 6 px, 폰에서 약 2~3 px로 확인).
3. **탭 반응**: 탭한 다음 프레임에 그 지점에서 링이 시작된다. 두 손가락 동시 탭은 방울 두 개가 된다.
4. **판독**: 첫 장면에서 울림돌 5개 모두, 가장 먼 돌까지 포함해 2마디 안에 최소 한 번씩 울린다. 진동자에서 8 cm 떨어진 울림돌(태)이 진동자 파열만으로 연타하지 않고, 점적기 링이 도달할 때 타격한다.
5. **단일 시계**: 소리를 켜고, ½박 점적기에서 박자 링 n = 4(1박) 위에 스냅한 울림돌의 타격 16회를 측정했을 때 박 격자 대비 ±15 ms 안에 든다. 4배 CPU 스로틀에서도 명판에 `시간 ×…`이 뜨면서 점적기 소리와 울림돌 타격의 상대 박자는 50 ms 안에서 유지된다.
6. **c_eff**: 방울 링 피크가 n = 4 박자 링을 지나는 시각이 1박의 ±3% 안이다. 명판의 1박 거리가 그려진 링 간격과 같다.
7. **메아리 북**: 라벨이 `메아리 1.00박`(±0.02)이다. 중앙 방울 뒤 최소 4회 연속, 1박마다 중앙 재집속이 보이고 중앙 울림돌이 그 시각에 울린다.
8. **안정성**: 공명실 프리셋에서 소파 장치를 끄고 진동자를 모드 주파수에 60 s 맞춰 두어도 파동장이 리셋되지 않고 NaN이 없다. 밝기는 포화하고 공명 게이지는 상한 근처에서 멈춘다(g_auto 동작).
9. **좌표 보존**: 창 크기를 바꾸거나 폰을 회전해도 파동이 끊기지 않는다. 벽과 오브젝트의 상대 위치, 각 울림돌의 음정·팬, 타원 초점 배치가 그대로다.
10. **모바일 레이아웃**: 360~430 px 폭에서 가로 스크롤이 없다. 도구 탭은 44 px 이상이다. 계기판 시트가 45vh 안에서 세로로 스크롤된다. 두 번째 손가락은 어떤 도구에서든 물 손가락으로만 동작한다.
11. **키보드만으로**: 도구 선택(1~7), 조준경 이동, 울림돌 놓기, Enter+화살표로 벽 그리기, Enter 550 ms로 치우기, Tab으로 계기판 조작이 모두 된다. 모든 포커스 대상에 황동 포커스 링이 보인다.
12. **감쇠 모드**: 켜면 시간 ×0.4, 대비 ×0.6, 자동 비 끔, 스트로보 disabled, 확장 링 없음이 모두 적용된다. 실행 중에 켜고 꺼도 된다.
13. **탭 숨김**: 숨긴 동안 rAF가 멈춘다. 돌아왔을 때 몰아치는 스텝이나 쌓인 소리 폭주가 없다.
14. **폴백**: WebGL2를 막으면 같은 팔레트로 간이 투영이 나오고 명판에 표시된다. `WEBGL_lose_context`로 소실시키면 한 프레임 안에 폴백으로 넘어가고, 복구하면 GL로 돌아온다. 그동안 음악이 끊기지 않는다.
15. **성능**: 중급 노트북 60 fps(솔버 ≤ 3 ms/프레임), 중급 폰 30 fps 이상. 두 기기 모두 첫 장면에서 시간 팽창 표시가 뜨지 않는다.
16. **오디오 안전**: 소리를 켜기 전에는 AudioContext가 생성되지 않는다. 비 모드 + 소파 끔에서 타격 보이스 ≤ 28, 타격 ≤ 40/s가 지켜지고 출력이 클리핑되지 않는다.
17. **캘리퍼**(P1): 유리판 지연선 뒤 울림돌의 실측이 직선 예측보다 크게 나온다(+10% 이상). 깊은 물 직선 경로에서는 ±3% 안이다.
18. **되돌리기·지우개**(P1): Ctrl/Cmd+Z가 마지막 기하 변경을 되돌린다. 지우개가 획을 나누고 유리를 부분적으로 지운다.
19. **스트로보**(P2): 기본은 끔이고 켤 때 안내가 뜬다. f_s > 3 Hz에서 홀드 교체가 70 ms 크로스페이드로 이뤄지고, 화면 전체가 계단식으로 번쩍이지 않는다.
20. **테마**: OS가 라이트이면 명판·레일·계기판이 라이트 크롬으로 바뀌고 투영면은 그대로다. body 배경이 두 테마 모두 명시되어 있다.

## 10. 이번 범위 밖

- 카메라 확대·이동, 핀치 줌.
